01 — Focus

Where the time actually goes

Four areas where repeated manual work turned into something reproducible.

Client deployment

Windows 11 installs that run without an audience: answer files, debloat, sane privacy defaults and software rollout in a single pass.

  • autounattend.xml
  • winget package lists
  • Office Deployment Tool

Active Directory

Domain joins, group policy, and above all the password lifecycle: expiry at the morning logon rather than mid-shift, so the help desk stays quiet.

  • Domain join & rename
  • Password lifecycle
  • Logon reporting

Linux & containers

Proxmox underneath, LXC and Docker on top. Compose stacks that live versioned in a repository instead of in somebody's shell history.

  • Proxmox & LXC
  • Docker Compose
  • VS Code tunnel

Monitoring

Custom PRTG sensors for the things the stock sensors stop at — such as Ookla speedtests that end up as a time series instead of a gut feeling.

  • PRTG custom sensors
  • InfluxDB time series
  • Scheduled measurements

03 — Projects

Selected work

Some of it sits in private repositories, because it describes an employer's infrastructure. Happy to describe it; code on request only.

it-toolkit

private

Nine separate repositories merged into one source of truth: Windows setup, Office installer, AD tooling, deployment, monitoring and Linux helpers behind a shared PowerShell module.

  • PowerShell
  • Active Directory
  • winget

windows-setup

private

Unattended client setup: system tweaks, debloat, privacy defaults and software rollout, driven by a profile JSON. Starts from a batch file and runs through without asking anything.

  • PowerShell
  • Windows 11
  • Unattended

ad-password-lifecycle

private

Moves forced AD password changes to the morning logon instead of lunchtime, and defuses the ActiveSync lockout waves that otherwise roll through the mailboxes afterwards.

  • PowerShell
  • Active Directory
  • Exchange

Behnke-Sprechstellen-Steuerung

public

Driving Behnke SIP door intercoms from the command line instead of the vendor's configuration tool.

  • SIP
  • Building tech

pizero-kioskos

private

Image builder for Raspberry Pi Zero kiosk systems, plus a menu display that a Pi Zero 2 W pushes out over HDMI. Small, silent, and happy to run unattended for weeks.

  • Raspberry Pi
  • Linux
  • Kiosk

registration-app

private

Frontend, backend and database for the sign-ups to a volunteer fire brigade's yearly seasonal campaign. Unpaid work, but with a proper data model.

  • Web
  • MySQL
  • Volunteer
