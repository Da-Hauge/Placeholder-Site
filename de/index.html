01 — Schwerpunkte

Wo die Zeit tatsächlich hingeht

Vier Bereiche, in denen aus wiederkehrender Handarbeit etwas Reproduzierbares geworden ist.

Client-Deployment

Windows-11-Installationen, die ohne Zuschauer durchlaufen: Antwortdateien, Debloat, vernünftige Datenschutz-Defaults und Softwareverteilung in einem Durchgang.

  • autounattend.xml
  • winget-Paketlisten
  • Office Deployment Tool

Active Directory

Domain-Beitritt, Gruppenrichtlinien und vor allem der Passwort-Lebenszyklus: Ablauf an der Morgenanmeldung statt mitten im Betrieb, damit die Hotline ruhig bleibt.

  • Domain Join & Rename
  • Passwort-Lifecycle
  • Logon-Reporting

Linux & Container

Proxmox als Unterbau, LXC und Docker darüber. Compose-Stacks, die versioniert im Repository liegen statt in irgendeinem Terminal-Verlauf.

  • Proxmox & LXC
  • Docker Compose
  • VS Code Tunnel

Monitoring

Eigene PRTG-Sensoren, wo die Standardsensoren aufhören — zum Beispiel Ookla-Speedtests, die als Zeitreihe landen statt als Bauchgefühl.

  • PRTG Custom Sensors
  • InfluxDB-Zeitreihen
  • Geplante Messläufe

03 — Projekte

Ausgewählte Arbeiten

Ein Teil davon liegt in privaten Repositories, weil dort die Infrastruktur eines Arbeitgebers beschrieben ist. Beschreibung gerne, Code nur auf Anfrage.

it-toolkit

privat

Neun einzelne Repositories zu einer Quelle der Wahrheit zusammengeführt: Windows-Setup, Office-Installer, AD-Werkzeuge, Deployment, Monitoring und Linux-Helfer hinter einem gemeinsamen PowerShell-Modul.

  • PowerShell
  • Active Directory
  • winget

windows-setup

privat

Unbeaufsichtigtes Client-Setup: Systemtweaks, Debloat, Datenschutz-Defaults und Softwareverteilung, gesteuert über ein Profil-JSON. Startet aus einer Batch-Datei und läuft ohne Rückfragen durch.

  • PowerShell
  • Windows 11
  • Unattended

ad-password-lifecycle

privat

Verschiebt erzwungene AD-Passwortwechsel auf die Morgenanmeldung statt auf die Mittagszeit und entschärft die ActiveSync-Sperrwellen, die sonst danach über die Postfächer rollen.

  • PowerShell
  • Active Directory
  • Exchange

Behnke-Sprechstellen-Steuerung

öffentlich

Ansteuerung von Behnke-SIP-Sprechstellen — Türsprechanlagen aus der Kommandozeile statt aus dem Herstellerkonfigurator.

  • SIP
  • Gebäudetechnik

pizero-kioskos

privat

Image-Builder für Raspberry-Pi-Zero-Kiosksysteme, plus ein Speiseplan-Display, das ein Pi Zero 2 W über HDMI ausgibt. Klein, lautlos, läuft wochenlang ohne Betreuung.

  • Raspberry Pi
  • Linux
  • Kiosk

registration-app

privat

Frontend, Backend und Datenbank für die Anmeldungen zur jährlichen Saisonaktion einer Freiwilligen Feuerwehr. Ehrenamt, aber mit ordentlichem Datenmodell.

  • Web
  • MySQL
  • Ehrenamt
