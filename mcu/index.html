The tracker ships with a fixed, offline dataset by default — no network request happens unless you add your own free TMDb API key here. If you do, this page will contact api.themoviedb.org and image.tmdb.org directly from your browser, using your key, to show posters and refresh ratings. The key is stored only in this browser (localStorage) and is never sent anywhere except to TMDb itself.
